A program that writes one weird job title — "Night-Shift Taste Tester for Expired Airline Pretzels" (53 characters) — to `/output/entry.txt` for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty. A blind judge compares titles two at a time and picks the weirder, funnier one; this title is a real-sounding job (taste tester) with one hilariously specific twist (night shift, expired, airline pretzels).

## Run it

```sh
python3 main.py
```

This writes the title to `/output/entry.txt` (53 bytes, UTF-8, no trailing newline).
